VERSI SPCK DIRECT RUN

1. Extract ZIP sebagai project baru di SPCK.
2. Pastikan index.html berada di root project.
3. Tekan Run. Tidak perlu npm run dev.
4. Koneksi internet diperlukan saat pertama kali membuka karena React/Tailwind/libraries dimuat dari CDN.

Source TypeScript asli tidak disertakan dalam paket direct-run ini agar SPCK tidak salah menjalankan TSX. Gunakan ZIP versi source untuk development Vite.
